# 桌面代理守护应用需求

## 已确认

- macOS 主窗口与菜单栏状态图标；关闭主窗口后继续监控。
- 支持 Claude Desktop 和 Claude Code，可分别启用保护，仅处理当前用户明确识别的目标进程。
- 实现代理检测、启动门禁、持续监控、异常锁定、手动恢复。
- 第一版采用进程级急停，接受检测及终止之间存在时间窗口，不承诺网络层零直连。
- 适配 Clash Party。
- 出口规则参考 claude-switcher：默认使用 Cloudflare trace 返回的地区与目标地区比较，普通 IP 变化只提醒。
- 增加可选的手动指定出口 IP 设置；填写并启用后，在地区检查之外增加地址严格匹配，不匹配时急停并锁定。未启用时不强制固定 IP。
- 自动检测负责展示当前出口，不自动更改用户指定的 IP 或目标地区。
- 提供可供用户验证功能的测试方式。
- 运行中网络不通或出口检测超时不触发急停，显示状态未知或网络告警并持续检测；不能将检测失败标为检查通过。
- 成功观测到不符合出口要求的地址才触发出口异常急停。用户重点关注预期日本出口变成其他国家或地区出口的情况。

## 环境发现

- 本机安装 Clash Party 2.0.4；配置目录为 mihomo-party。
- 保存的配置启用了 TUN，未启用系统代理，外部控制器地址未设置。
- 这些是静态配置事实，不代表实时代理、路由或端口健康。

## 后续确认

本轮关键行为已获用户确认：

- 确认代理内核退出或 TUN 关闭时急停并锁定。
- 启动和手动恢复必须取得有效出口并通过检查；网络未知时不放行。
- 提供不影响真实进程的模拟测试，以及用户明确触发的真实急停测试。

## 第一版实现约定

- 运行中持续校验地区和指定 IP，超出参考项目保镖仅检查代理进程与 TUN 的实现。
- 锁定且保护启用时，匹配到的外部启动也会在巡检后急停；不承诺阻止其第一个请求。
- 首次打开及重开默认观察模式，由用户显式启用进程保护；已有锁定持久化。
- 不安装 root 服务、不自动修改代理、不自动启动 Claude。

## 已实现与覆盖边界

- 使用系统路径的 Cloudflare trace；规范化 IPv4/IPv6 地址用于比较，但不完整验证双栈旁路或目标分流。出口探针通过不等于所有 Claude 流量均走同一路径。
- 本机巡检约 2 秒、网络检测约 10 秒，网络请求有超时，两个监控循环独立。
- 急停限定当前用户与明确路径，复核进程启动身份；先 TERM，再对仍存在的匹配进程 KILL。
- 锁定持久化，启动和手动恢复都重新检查；CLI 在终端实际执行前再检查心跳及门禁。
- 使用说明和测试步骤见 README.md 与 docs/testing.md。
